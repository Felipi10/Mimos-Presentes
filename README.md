# Mimos Presentes — site inicial

Projeto inicial em HTML, CSS e JavaScript, pensado para ser fácil de editar e publicar.

## Próximos passos
1. Trocar o número do WhatsApp em `index.html`.
2. Colocar o logo real da Mimos Presentes.
3. Substituir os blocos de demonstração pelas fotos reais dos produtos.
4. Definir cores finais da marca.
5. Adicionar preços, Instagram, endereço e/ou catálogo, se desejado.
6. Publicar no GitHub Pages, Vercel ou outro serviço.

O layout é responsivo e funciona em celular, tablet e computador.
